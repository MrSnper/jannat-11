موقع رسالة جنّات 11:11 ❤️

الملفات الثلاثة:
• index.html : صفحة الرسالة
• letter.jpg : الصورة الأصلية للرسالة بدون تعديل
• music.mp3 : الأغنية التي أرسلتها (الحب الأبدي، أصالة وماجد المهندس)

طريقة عمل الموقع:
عندما تفتح جنّات الرابط، تظهر شاشة «افتحي رسالتكِ». عند الضغط عليها تظهر الرسالة كاملة وتبدأ الأغنية بالخلفية. يوجد زر أسفل الشاشة للإيقاف والتشغيل. معظم متصفحات الهواتف لا تسمح ببدء الصوت قبل الضغط، لذلك الزر ضروري.

نشر الموقع على GitHub Pages:
1) فك الضغط عن الأرشيف.
2) ادخل github.com وأنشئ مستودعاً جديداً (Public).
3) ارفع الملفات الثلاثة الموجودة داخل المجلد إلى جذر المستودع مباشرة، وليس المجلد نفسه.
4) Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
5) افتح الرابط الذي يقدمه GitHub Pages ثم أرسله إلى جنّات.

مهم: لم يتم نشر الموقع فعلياً بعد. حزمة الملفات جاهزة للنشر، والنشر العلني للأغاني المسجلة تجارياً قد يتطلب إذناً من أصحاب الحقوق.
